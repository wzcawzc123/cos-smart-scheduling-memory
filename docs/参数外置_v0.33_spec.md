# 参数外置 spec（v0.33 · 第1批完善）

> 目标：把 `ScenarioTactics` 的硬编码值抽成外部配置文件，实现「改配置即换策略，不重编译」。
> 依据：设计文档 v1.1 §4.4（parse → validate → compile policy → dry-run → commit）

## 1. 为什么做

现状：每个场景的参数都硬编码在 `runtime/include/policy_manager.hpp::tactics_for()` 里，
改一个数字要重编译 + 重刷模块（跨平台构建链 + qemu，分钟级）。这是"特调试参数"的最大摩擦。

## 2. 交付物

| 文件 | 作用 |
|---|---|
| `runtime/include/tactics_conf.hpp` | 纯逻辑：解析 + 校验 + 覆盖应用（host 可测） |
| `runtime/include/policy_manager.hpp` | 接配置：`set_tactics_conf()` + mtime 热重载 |
| `runtime/tests/test_tactics.cpp` | 单测：正常/坏配置/值域/未知场景/未知字段/部分覆盖 |
| `/sdcard/Android/UnifiedRootOptimizer/uro_tactics.conf` | 运行时配置（设备侧，数据目录根） |

## 3. 配置格式（INI 风格，不引入 JSON 解析器）

```ini
# URO 场景配方 v1
# 注释：# 或 //；空行忽略；-1 = 不干预/回基线
# 未出现的场景/字段 = 沿用内置默认（向后兼容）

[POWER_SAVE]
reclaim=1
freeze=1
maxKill=3
uagUp=2500

[PERFORMANCE]
uagHi=80
gpuIdle=120
cpuClamp=0
```

### 字段表（值域即校验规则）

| 键 | 目标字段 | 值域 |
|---|---|---|
| reclaim | reclaimEnabled | 0/1 |
| freeze | freezeEnabled | 0/1 |
| maxKill | maxKillPerRound | 0..20 |
| depth | depth | 空/cached/service |
| cooldown | cooldownSec | -1..3600 |
| uagUp | uagUpRateUs | -1..1000000 |
| uagDown | uagDownRateUs | -1..1000000 |
| uagHi | uagHispeedLoad | -1..100 |
| uagTl | uagTargetLoadsFirst | -1..100 |
| gpuIdle | gpuIdleTimer | 0..1000 |
| keepAdj | keepAliveAdj | -1..1000 |
| cpuClamp | cpuClamp | 0/1 |
| maxFreqK | maxFreqKhz | -1 或 300000..4000000 |
| handover | handover | 0/1（GAME 建议保持 1） |

## 4. 失败语义（dry-run 铁律）

- **任一行非法 → 整份配置拒绝**，不部分生效；运行态保持上一次成功值或内置默认
- 错误写 `events.log`（`TacticsConf` 行）+ telemetry，不改策略
- 文件不存在 → 静默走内置默认（不报错，向后兼容）

## 5. 热重载

同 `app_profiles.txt` 风格：靠 mtime 判断，文件改动才重新解析（避免每 tick 读盘）。

## 6. 验收标准

1. 配置不存在 → 行为与 v0.32.0 逐字段一致（回归）
2. 合法配置 → 对应场景字段被覆盖，未出现字段保持默认
3. 坏配置（未知场景/未知字段/越界/非数字）→ 整份拒绝 + 错误记录 + 运行态不变
4. 热改生效：改文件后下一次决策即生效（不需重启进程）
5. 单测覆盖 1-3，断言数并入 `run_test.sh`
