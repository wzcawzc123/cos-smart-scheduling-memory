# cpuset 掉帧实验协议 v1（10-07 原始问题 · 指挥链载体版）

> 2026-10-11 · UnifiedRootOptimizer E 阶段 · 载体=AppOpt 指挥链②（已实测通路）

## 1. 原始问题（M0 挂账）

收紧/调整前台 App 的 cpuset（如钉核、并核）是否引起掉帧——AppOpt×Oplus 互抢对帧
平整度的影响（10-07 结论：游戏区应豁免；通用区收益/风险未量化）。

```text
控制: uro.conf APPOPT_GAME_EXEMPT 不动；画像改完 60s 生效、删完 60s 撤销
```
