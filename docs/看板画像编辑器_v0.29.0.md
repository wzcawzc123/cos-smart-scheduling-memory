## 3. 设计决策

- **内联 Vue 3.5.43 `vue.global.prod.js`**，不引 CDN——KSU WebUI 是本地环境，外网不可靠。单文件从 26.9KB 涨到 218.6KB，WebView 加载无感。
- **in-DOM template**（卡内直接写 HTML + `{{ }}`），配 `[v-cloak]{display:none}` 防闪字；脚本里若 `typeof Vue === 'undefined'` 则显示兜底提示，不让卡片静默空白。
- **桥沿用看板既有实现**：`readCmd()`（成组 + `base64` + `tr -d '\n'`，绕开「ksu.exec 只回传最后一行」）、单命令行 + 顺序执行（避免分号聚合丢数据）。
- **写协议**（对齐 relay 要求）：`ls/stat` 取原始属主权限 → `cp` 备份 `app_profiles.txt.uro_bak_<epoch>`（保留最近 3 份）→ `echo <b64> | base64 -d > <file>.urotmp` → `chown/chmod` 对齐 → `mv -f`（rename 原子）→ `cat` 回读**逐字节比对**；每一步带 `&& echo ok || echo err` 判成败。
- **删除用两击确认**而不是 `confirm()`：KSU WebView 不保证实现 `onJsConfirm`，`confirm()` 可能直接返回 false。
- **解析对齐运行时**（`policy_manager.hpp::apply_profile` + `appopt.cpp::parse_profile_rules`）：`#` 起注释（行内注释保留）、含 `|` 且首字段非空才算画像行、其余行（注释/空行/AppOpt 风格规则）原样保留。
- **前端兜住运行时坑**：四字段行里 down/up 留空时，策略侧 `uS = atoi("…|cpuset") = 0` 会被当成"固定 0μs"（误改降频延迟）。
  编辑器写回四字段行时把空速率统一补 `-1`（等价语义），加载时对被改前的旧格式行给出告警。

## 4. 踩坑记录

1. **Vue `:disabled="a || b"` 的假值陷阱（真机卡了半小时）**：a、b 皆空时表达式求值为**空字符串**，Vue 对布尔型 DOM prop 走
   `includeBooleanAttr('')` → `true` → 按钮**永久 disabled**；而浏览器对 disabled 元素**连 click 事件都不派发**，
   症状是"点了没反应、click 日志也没有"。修法：`!!` 收敛成布尔。排查手段是临时给卡加 click 捕获日志 + 状态回显。
2. **KSU WebUI 的 WebView 内容不进无障碍树**（节点数恒 0）→ `tap_element`/`type_text` 用不上：
   定位靠 `observe_screen(include_screenshot=true)` + `locate_on_screen`（OCR，返回 screen 坐标），
   输入靠 shell `input text`（注入 KeyEvent，实测能正常触发 `input` 事件更新 v-model）。按钮很矮（~50 device px），**目测很容易偏**，务必用 OCR bbox 定位。
3. `input text` 只吃 ASCII/`%s` 空格写法；中文输入需换路径（本任务字段全为 ASCII）。
4. 每次关掉软键盘后页面会重排，**旧坐标立即失效**，下一次点击前重新定位。
