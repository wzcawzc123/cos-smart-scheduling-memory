# URO 看板重构 spec（v0.30.0）

> 2026-10-11 · 目标：把看板从「单列长滚动 + 键值堆」重做成「底栏 5 分区 + 可交互图表」的仪表盘
> **状态：已实现并通过真机验收**（见文末「实现结果」；CHANGELOG v0.30.0 有完整清单）
> 前置：v0.29.0（画像编辑器，内联 Vue 单文件）已上线

## 0. 一句话

**概览 / 趋势 / 画像 / 证据 / 关于** 五个分区，各自回答一个问题；趋势页用真图表（悬停十字准星 + 窗口切换）；
工程上拆成多文件，`index.html` 退化成几十行的壳。

## 1. 非目标

- 不动任何调度逻辑（本版仍是纯前端）
- 不引入构建步骤（改完直接推模块目录，保持"编辑即上线"的迭代方式）
- 不做桌面级 BI（不引 Chart.js 这类重库）

## 2. 信息架构（底栏 5 Tab）


## 3. 图表规格（数据源已实测）

| 图 | 源文件 | 字段 | 窗口 | 形式 | 交互 |
|---|---|---|---|---|---|
| 电池温度 | `thermal.jsonl` | battery(°C) | 1h/6h/24h | 面积图 | 十字准星 + tooltip |
| CPU 热点 | `thermal.jsonl` | top[] 取前 3 热点 | 同上 | 细折线 ×3 | 图例开关 |
| 卡顿率 | `fps.jsonl` | janky/frames×100（按 pkg 分段） | 同上 | 折线 + 柱（帧数） | 按 App 过滤 |
| 内存 | `telemetry.jsonl` | memAvailMb / psiMem10 | 同上 | 双轴折线 | tooltip |
| GPU | `gpu.jsonl` | gpuBusy% / gpuClkMhz | 同上 | 双线 | tooltip |
| 电量/电流 | `power.jsonl` | pct / mA（放电为负） | 同上 | 面积 + 折线 | tooltip |
| 档位占比 | `telemetry.jsonl` | scenario 计数 | 24h | 甜甜圈（手写 SVG） | 点击高亮 |
| 档位时间线 | `telemetry.jsonl` | scenario 序列 | 近 200 条 | 彩色分段条 | 点段看 why/fg |
| 核组分布 | `thread.jsonl` | groups{} | 最新 | 堆叠条 + 数值 | — |

**迷你 sparkline**（概览页）：温度 / 卡顿率 / 内存各一条，取近 1h，无坐标轴、无交互。

## 5. 数据管道与性能

- 桥沿用既有实现：`(cmd) | base64 | tr -d '\n'` + 前端解码；**单命令行**、按页并发（`Promise.allSettled`）
- **按 Tab 取数**：只跑当前页需要的段（现状 14 条全跑 → 概览页 6 条）
- **awk 预聚合**：多行日志 → 单行 CSV（`ts,值,值`），把 300 行 telemetry（~60KB）压到 ~6KB 再进 WebView
- **窗口→行数映射**（实测频率）：telemetry ~12s/条 → 1h≈300、6h≈1800、24h≈7200（>1000 行走 awk 降采样到 600 点）；thermal/power/fps 60s/条 → 1h≈60
- **时间基准差异（实测踩点）**：`telemetry.jsonl` 的 `ts` 是**秒**，`thermal/power/fps/gpu/thread` 是**毫秒** → 统一在前端归一化
- **刷新策略**：概览 5s（仅状态段）｜趋势 30s 且仅当前 Tab｜证据 30s｜画像/关于 手动；页面隐藏（`visibilitychange`）暂停轮询
- **降级**：任一段缺失 → 该卡显示"暂无数据"，绝不留白或报错刷屏

## 6. 设计语言

- 调色板沿用奶油粉 Nexus（与 COSMemory 面板同族），**新增深色主题**（`prefers-color-scheme` 自动切换 + 变量一套到底）
- 组件：滚动收缩大标题 / 分段控件（窗口切换）/ 卡片网格（2 列小卡 + 全宽大卡）/ **iOS 药丸底栏**（图标 + 文字 + 选中态）/ 骨架屏 / 空态
- 图表配色与卡片同源（同一组语义色：档位 / 温度 / 卡顿 / 内存 / 电量）
- 动效：Tab 切换淡入位移、数字滚动、图表 200ms 入场；尊重 `prefers-reduced-motion`

## 10. 实现结果（2026-10-11 真机验收）

**文件**（`module/webroot/`）：`index.html` 35KB（壳 + in-DOM 模板 + Solar sprite）· `style.css` 16KB · `app.js` 39KB ·
`assets/`（vue.global.prod.js 168KB / uplot.iife.min.js 51KB / uplot.min.css 1.9KB）

**与 spec 的偏差**：
- 图表只上 uPlot（不引 Chart.js）；甜甜圈/堆叠条/热力色带用手写 SVG+CSS（体积与风格都更划算）
- 证据页「档位时间线」原设计是分段色带，实测**真机档位几乎逐条切换**（均衡 43% : 性能 42% 交替），
  合并连续段仍有上百段 → 改为 **40 格热力条**（按桶取多数档，深浅 = 主导占比）
- 前台占比从三列网格改为「包名整行 + 下方进度条」（窄屏可读性）

**真机踩坑（均已修）**：多行状态文件必须走 `rd()`；uPlot 时间轴要秒；in-DOM 模板 `<use :href>` 动态绑定不生效（改静态）；
色带摩尔纹；包名列折行。

**验收**：离线 `webui_profile_test.mjs` 29/29 · 浅色/深色各一轮截图 · 五页均出数 · 底栏与图标正常 ·
发布件 md5 见 CHANGELOG / Release。
